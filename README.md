# 🎮 Mini Site em HTML - Atividade 03

Este projeto é um mini site desenvolvido como parte da **Atividade 03** da disciplina de Desenvolvimento Web. O objetivo da atividade é aplicar conceitos de HTML5 semântico, boas práticas de navegação e versionamento de código utilizando Git e GitHub.

---

## 📌 Tema do Projeto
**Tema:** Jogos Eletrônicos (*The Last of Us Part II*)

O site apresenta informações sobre a história, características principais e curiosidades do jogo, além de um formulário de contato funcional e um trailer incorporado via YouTube.
